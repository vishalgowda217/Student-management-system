# 🎓 Student Management System

A simple web-based Student Management System developed using **Node.js, Express.js, EJS, and MySQL**.

The application performs basic **CRUD (Create, Read, Update, Delete)** operations for managing student records.

## 📌 Project Overview

The Student Management System allows users to:

- Add new student records
- View all student records
- Edit student details
- Delete student records
- Store student information in a MySQL database

## 🛠️ Technologies Used

- HTML
- CSS
- EJS
- Node.js
- Express.js
- MySQL
- mysql2
